# 视觉识别 V2

V2 是一条重新实现的比赛识别链路。它不继承 V1 的圆检测、固定物排除区、
端点吸附、左右差异化偏置和多层回退规则，只保留机构本身能够保证的约束。

## 处理链路

```text
右端绿色管段
  -> 更新“固定左端 + 随动右端”的一维轴线
  -> 在轴线窄带内做一次暗中性色 LAB 连通域搜索
  -> 用球直径派生尺寸、密度、轴向范围和横向距离门限
  -> 连续性选点
  -> Alpha-Beta 位置/速度滤波
  -> 兼容层生成原有日志、UDP 和 UART 字段
```

主路径每帧只有一次钢球 `find_blobs`。有轨迹时搜索预测点附近的小窗口；
漏一帧后下一帧直接回到完整轴线窄带，不在同一帧串行执行多套算法。管道姿态
每 4 帧更新一次，连续过期后明确输出无效数据。

## 状态和参数

实现位于 `maixcam/vision_v2.py`。内部使用 `Point`、`Axis`、`Candidate`、
`PipeState`、`TrackState` 和 `DetectionResult`，均为具名字段对象；只有
`legacy_detection()` 与 `legacy_state()` 会在系统边界生成兼容字典。

安装标定只有 9 个字段：

1. 画面宽、高；
2. 左、右参考端点；
3. 右端搜索区域；
4. 管道与钢球两组 LAB 阈值；
5. 钢球直径；
6. 目标位置（按稳定的 LAB 可观测中心标定）。

尺寸上下限、像素数、轴线距离、局部窗口和最大帧间位移都由钢球直径派生。
在线调参只保留 `target_position`；其余项属于安装标定，修改代码后走完整测试。

## 启用和回退

`maixcam/ball_config.py` 默认配置：

```python
VISION_ALGORITHM = "v2"
```

需要临时对照时改为 `"v1"`，串口、RTSP、UDP、录像和 CSV 格式均不变。
V1 文件暂时保留用于 A/B 验证，不再作为 V2 的依赖。

## 当前验证

- V2 单元测试覆盖：两帧建轨、局部/全局切换、短时续航、姿态过期、冷启动
  姿态确认、连续性选点、轴线变化和在线配置边界。
- 全仓库测试共 104 项通过。
- 对 `stream_20260730_173003` 的 8519 帧录像做了 OpenCV 等价阈值离线抽样：
  V2 简化几何门控在每 4 帧抽一帧时，候选帧占比约 35.8%，每帧最多 2 个候选。
  该结果用于检查候选覆盖和固定误检，不等同于带人工真值的准确率。

部署前仍需在实机按“空管、静止、慢滚、快滚、换向、短遮挡”顺序做一轮
标记录像。V2 的目标是先保持结构稳定，再依据可复现的失败样本决定是否增加
一条通用约束；不为单帧现象新增特例。
